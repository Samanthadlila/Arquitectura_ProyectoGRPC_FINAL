# Food Delivery

## Descripción

Aplicación web de entrega de comida desarrollada con React, Node.js, Express, MongoDB Atlas y Docker.

## Requisitos

* Docker Desktop
* Conexión a Internet

## Ejecución

Desde la carpeta principal del proyecto ejecutar:

```bash
docker compose up --build
```

## Accesos

### Frontend (Cliente)

http://localhost:5173

### Panel de Administración

http://localhost:5174

### Backend

http://localhost:4000

### API de Productos

http://localhost:4000/api/food/list

## Base de Datos

La aplicación utiliza MongoDB Atlas para almacenar usuarios, productos y pedidos.
